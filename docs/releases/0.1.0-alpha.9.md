Open JARVIS alpha.9 修复 alpha.8 安装后发送消息出现“MAF 组件未安装”的问题。客户端内置任务执行所需的 Python 运行时和依赖，用户无需安装 Python，也无需运行 pip 或安装脚本。

### 本次修复

- 补齐安装包遗漏的 MAF OpenAI provider。此前代理模块可以导入，但实际执行任务时加载的独立实现包没有被收集。
- 发布自检改为真正调用 MAF：总控委派 writer，经本地 HTTP/SSE 完成四轮模型交互、调用文件工具并核对实际生成的中文文件与回答。该检查失败时停止生成安装器和发布。
- 安装版发生组件缺失时提示更新或重新安装完整客户端，避免让用户执行不适用于安装版的 pip 命令。

### 升级与首次使用

本次修复不改变用户配置、数据目录和模型安装格式；升级后继续使用已有配置与已下载的语音模型，无需因这次修复重新下载。

首次使用仍需从语音条右键菜单打开设置，填写任务模型的接口地址、模型名称和 API Key，并在设置页下载语音识别与语音合成模型。设置中的 ⓘ 提供各厂商填写说明。未配置任务模型时为命令演示模式；本版不内置云端模型账户或 API Key。

在下方 Assets 中选择安装器：

| 平台 | 安装器 |
| --- | --- |
| macOS Intel，macOS 14+ | `open-JARVIS-0.1.0-alpha.9-macos-x64.dmg` |
| macOS Apple Silicon，macOS 14+ | `open-JARVIS-0.1.0-alpha.9-macos-arm64.dmg` |
| Windows x64 | `open-JARVIS-0.1.0-alpha.9-windows-x64-setup.exe` |

每个安装器附带 `.sha256` 校验文件与 `.manifest.json` 构建清单。
