Open JARVIS alpha.10 增加连续对话、输入框语音转写与自动发送，并改进工具目录和网页读取。

### 使用变化

- 一个对话对应一个 session，每次输入与回答对应一个 run；补充问题也创建关联的新一轮。重启沿用当前对话，旧记录自动迁移。
- 点击「新建对话」或说出「新建对话」才创建新的 session；左栏可切换旧对话和各轮结果。
- 默认先说一次“贾维斯”，之后可连续对话，直到点击暂停。临时识别文字出现在输入框，一句结束后最终文字自动发送；不重复发送临时识别，切换对话会丢弃未发送语音。
- 右上角扳手图标展示真实工具和专业助手、用途及参数，可搜索；保留默认文件预览和后台语音播报。
- 网页读取默认 Markdown，改善中文编码、正文清理、压缩和重定向；长页面可以继续读取同一快照，失败原因更明确。

本轮参考 [OpenCode 与 Claude 官方 SDK 的公开设计](https://github.com/ecojust/open-JARVIS/blob/master/docs/architecture/agent-tools-2026-10-31.md)，继续使用 MAF 编排，不增加浏览器运行时。

### 下载与升级

在下方 Assets 选择 macOS Intel、Apple Silicon（均 macOS 14+）或 Windows x64 安装包。安装包内置 Python 和任务依赖，无需运行安装脚本。已有设置、任务产物与语音模型继续沿用。

| 平台 | 安装器 |
| --- | --- |
| macOS Intel | `open-JARVIS-0.1.0-alpha.10-macos-x64.dmg` |
| macOS Apple Silicon | `open-JARVIS-0.1.0-alpha.10-macos-arm64.dmg` |
| Windows x64 | `open-JARVIS-0.1.0-alpha.10-windows-x64-setup.exe` |

首次使用仍需在设置填写任务模型接口、模型名称和 API Key，并点击下载语音模型。未配置任务模型时为明确的命令演示模式。
