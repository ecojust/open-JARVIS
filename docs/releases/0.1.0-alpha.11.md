Open JARVIS alpha.11 增加每轮工具执行记录，将每个 run 的工具调用上限提高到 1000 次，并明确显示语音唤醒状态。

### 使用变化

- 在同一对话的不同 run 中查看各自的工具调用和专业助手委派。记录保留执行状态，参数与结果按需展开，重启后仍可查看；完整 Agent 文字回答继续收在「查看回复」里。
- 每个 run 默认最多调用 1000 次实际工具，主 Agent 与专业助手共用。模型请求和内部轮数同步调整，保留 5 分钟执行超时及手动取消；达到任一限额会保存已完成部分。
- 设置增加「桌面语音条始终置顶」，默认开启，保存后立即生效并跨重启保留。只改此开关不会重启后台或语音模型。
- 保留默认唤醒词「贾维斯」。可以先说名字再说任务，也可以说「贾维斯，帮我……」。唤醒后可连续对话，点击暂停后需重新唤醒。
- 未唤醒时，桌面语音条显示「等待唤醒」，输入框提示先说名字。收到了未带唤醒词的语音时，会解释未发送的原因。
- 唤醒后继续在输入框显示临时识别文字，一句结束后自动发送。TTS 临时暂停收音与切换对话仍保留唤醒状态。

### 下载与升级

在下方 Assets 选择 macOS Intel、Apple Silicon（均 macOS 14+）或 Windows x64 安装包。安装包内置 Python 和任务依赖；已有设置、对话、产物与语音模型继续沿用，无需重新下载模型。

| 平台 | 安装器 |
| --- | --- |
| macOS Intel | `open-JARVIS-0.1.0-alpha.11-macos-x64.dmg` |
| macOS Apple Silicon | `open-JARVIS-0.1.0-alpha.11-macos-arm64.dmg` |
| Windows x64 | `open-JARVIS-0.1.0-alpha.11-windows-x64-setup.exe` |

首次使用仍需配置任务模型，并在设置页下载语音模型。
