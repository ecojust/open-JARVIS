Open JARVIS 首个公开开发预览，支持 macOS Intel、Apple Silicon 和 Windows x64。

### 下载

在下方 Assets 中选择对应安装器：

| 平台 | 安装器 |
| --- | --- |
| macOS Intel，macOS 14+ | `open-JARVIS-0.1.0-alpha.8-macos-x64.dmg` |
| macOS Apple Silicon，macOS 14+ | `open-JARVIS-0.1.0-alpha.8-macos-arm64.dmg` |
| Windows x64 | `open-JARVIS-0.1.0-alpha.8-windows-x64-setup.exe` |

每个安装器附带 `.sha256` 校验文件和 `.manifest.json` 构建清单。安装包包含运行依赖，语音模型通过客户端设置页下载。

### 本版功能

- 常驻桌面的山羊语音胶囊，真实声浪展示，点击暂停／继续接听，展开为最大化工作空间。
- 本地 SenseVoice 语音识别与 Kokoro 中文播报；模型下载支持多源、换源续传、进度与预计剩余时间。本版修复多文件下载的进度闪烁。
- 工作空间默认展示生成文件；完整文字回复按需打开，后台语音播报独立运行。
- 本地 Agent 编排与检索、文档、表格、演示、排班及讲解视频工具；任务模型支持配置 OpenAI-compatible 接口。
- 加宽的设置页及 ⓘ 厂商填写说明，包含 DeepSeek、OpenAI、阿里云百炼和 Ollama。

### 首次使用

从语音条右键菜单打开设置，填写任务模型接口、模型名称和 API Key，再下载语音识别与语音合成模型。DeepSeek 示例为 `https://api.deepseek.com` / `deepseek-flash`。未配置任务模型时为命令演示模式。
