# 持续对话、语音输入与工具验证

日期：2026-10-31。本轮实现持久化 session、一问一答一个 run、输入框语音预览及最终自动发送、工具目录和网页正文读取。本文将真实模型录音回放、真实桌面/后台验收与生产模型、真机音频验收分别记录。

## 实际行为

- SQLite v3 自动迁移既有 tasks/messages，最早原型无 task 的问答也归档成历史 run；当前 session 持久化，重启、暂停、普通输入均不创建新 session。
- 只有显式新建操作创建 session。每次提交或补充创建一个新 run，兼容 `run_id=task_id`；补充关联前一轮并使用新预算，旧问题保留并标记已继续。
- 读取当前 session 的既往问答与产物，避免其他会话或未来排队输入进入当前模型请求。SQL 使用 session 索引与 rowid 顺序，有界提取最近 24 轮；先前资料不是新的执行授权。
- SenseVoice 离线模型提供限频输入框预览，句子结束才提交最终文本。最终事件按句子 ID 去重；切换对话以丢弃确认和 generation 阻止迟到语音，保留手写草稿及网络失败重试文字。
- 默认唤醒一次后可以连续说话；用户暂停结束唤醒状态但不更换 session。TTS 临停与会话切换保留唤醒状态，音频进程重启需重新唤醒。
- 右上工具图标读取真实注册目录，当前 MAF 提供 18 个工具和 4 个专业助手委派入口；native 模式不宣称具有委派能力。目录不加载模型、MAF 或语音权重。

## 自动化与真实桌面

本地完整 **362 项测试通过**，Ruff 通过；原生构建结果由上层 [验证记录](../../VALIDATION.md) 记录。专项覆盖迁移、重启、排队历史隔离、续接幂等与新预算、跨会话父轮拒绝、旧问题不再激活、语音暂停/切换/过期确认/重复最终事件、网页压缩/编码/跳转/分页和模型上下文裁剪。

[桌面验收 JSON](ui/ui-acceptance.json) 使用真实 Qt、自己启动的后台服务、HTTP/SSE、SQLite 和文件读写：前两轮实际写入/读取文件，第三轮回放实际 SenseVoice 识别事件；4 个 partial 仅更新输入框，重复 final 只创建一个 run。工具图标实际加载 22 项目录，语音新建对话后可以切回并查看原来的 3 轮。

后台使用明确的 demo 工具。语音自然语言输入在未配置模型时返回待配置提示，不能把本次 UI 验收说成生产模型已经自主完成文章。MAF 的实际模型协议、委派和文件写入另由本地 HTTP/SSE fixture 测试及冻结程序自检覆盖。

复现脚本：`python scripts/acceptance_session_ui.py`。脚本使用本目录已记录的 STT 事件，既不重下模型也不访问真实音频设备。

## 真实本地语音模型回放

[单句记录](voice-replay.json) 使用已安装 Kokoro 合成 8.52 秒中文 PCM，经真实 WebRTC VAD 和 SenseVoice 识别，生成 4 次临时文字、1 次最终文字。临时文字有实际纠错过程，因此只发送 final。仅 sounddevice 输入流换为按时序播放录音，没有真实麦克风或扬声器。

[连续两句记录](continuous-voice-replay.json) 的第一句带“贾维斯”，第二句不带唤醒词，两句均识别正确，共 7 次 partial、2 次 final。中间模拟 TTS 的临时暂停/恢复，确认唤醒状态保留。记录保留 PCM 摘要、模型名称、代码摘要及真实事件时刻，不把音频大文件提交到仓库。

预览最小间隔 1.5 秒，慢 CPU 上按上次推理耗时的两倍降频；最多一个待处理预览、三个完整语句等待识别，最终识别优先。音频回调不推理、不落盘，不新增常驻模型。

## 实际网页读取

[联网检查](webfetch-live.json) 实际访问 Fed、ECB、UN 文章及 IMF 资讯，读取正文、来源、类型与编码；长文在同一随机 `page_id` 上通过 `next_offset` 继续读取，不重新请求网页。ECB 目录的跳转也实际经过固定来源校验；依赖 JavaScript 的动态目录仅返回少量标题并明确提示限制。

正文提取保留段落、标题与有用来源链接，识别语义 main/article 及等价标记，移除导航、分享按钮、空锚点和脚本。UTF-8、BOM、header/meta 声明与 GB18030 均有验证。下载/解压各限 4 MiB，正文提取限 20 万字符；快照最多 4 份/80 万字符、5 分钟过期。截断区分分页与提取上限，模型输入进一步裁剪时仍保留正确续读位置。

实际联网成功不是所有网站兼容承诺。当前不执行 JavaScript，不登录或绕过验证码，不解析 PDF/Office URL；错误保留可操作原因，未知来源保留公共 IP 校验和绑定。

## 性能与验收边界

[30 次启动测量](performance.json)：Linux offscreen 的语音条启动 P95 **228.9 ms**、RSS P95 **75.8 MiB**。这是单个语音条进程的开发测量，未包含后端和模型，不作为 macOS/Windows 完整持续监听性能验收。

尚未执行真实麦克风/扬声器、生产模型自由任务、三端干净系统安装和全部性能预算验收。三端候选构建与发布结果会另行补充；不能用上述本地结果代替原生安装包证据。
